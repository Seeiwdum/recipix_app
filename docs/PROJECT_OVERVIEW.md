# Recipix — สรุปความเข้าใจ (10 บรรทัด)

1. Recipix คือแอปมือถือช่วยคนไทยรายได้ประจำบริหาร "ของในตู้เย็น + เงินค่ากิน" ให้รอดถึงวันเงินเดือนออก
2. Survival Engine: แคลอรี่ของที่ยังไม่หมดอายุ ÷ 2,000 = วันที่อยู่ได้; งบ ÷ วันที่เหลือ = งบต่อวัน; ขาดเท่าไรบอกตรงๆ (BudgetDeficit, ADR-002)
3. ของที่เหลือ 0-2 วันถูกดึงขึ้นมาเตือนเป็น "ต้องใช้ก่อน"; ของปริศนา (ยังไม่รู้ชนิด) นับแคลอรี่แยกเป็นค่าประมาณ
4. Slot Machine สุ่ม 3 วัตถุดิบ (เน้นของใกล้หมดอายุ หรือสุ่มอิสระ) แล้วจับคู่สูตรแบบเซต บอก % เข้ากัน และของที่ขาด ผลถูกตัดสินก่อนแอนิเมชัน
5. ทำเมนูแล้วตัดสต็อกตามปริมาณ/หน่วยของสูตร (FEFO) ไม่ใช่ลบทั้งชิ้น
6. Badge มาจากกฎที่ประเมินเหตุการณ์ (ใช้ของใกล้หมดอายุ, อยู่ในงบติดกัน 7 วัน ฯลฯ) และกระจายผ่าน Stream
7. ย้ายจาก Unity มา Flutter แล้ว (ADR-001); logic ธุรกิจอยู่ใน `packages/recipix_core` (Dart ล้วน มีเทสต์)
8. UI ใหม่: "ครัวกระดาษ" พื้นครีม สีเน้นเขียวสมุนไพรเดียว SVG วาดเอง ห้าม Emoji/gradient/glow — ต้องดูเป็นเครื่องมือ ไม่ใช่โฆษณา
9. 5 แท็บ: หน้าหลัก (ใบรายงานประจำวัน), ตู้เย็น (เกมจัดตู้เย็น), สแกน (กล้องจริง), สุ่มเมนู (วงล้อ 3 แกน), แดชบอร์ด (คง Badge เดิม แก้ส่วนอื่น)
10. ยังไม่มีต้นฉบับ Unity/เดโม HTML/สเปก UI ฉบับเต็มในรีโป — ใช้ MASTER_PROMPT เป็นสเปกหลักจนกว่าจะได้ไฟล์
