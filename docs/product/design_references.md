# แหล่งอ้างอิงดีไซน์

## Figma ของเพื่อนร่วมทีม — "Cookmate" (ส่งมา 2026-10-16)
ลิงก์: https://www.figma.com/design/GsLe2idYEkQP2QntyIfmzF/Untitled
สถานะการเข้าถึง: Figma connector ของ Claude ไม่มีสิทธิ์เปิดไฟล์ (ต้องให้สิทธิ์ editor ถ้าจะดึงโครงสร้าง/สีอัตโนมัติ) — ดูผ่านโหมด view-only ในเบราว์เซอร์ได้
ผู้ก่อตั้งยืนยัน: **ใช้สไตล์ minimal ของ Recipix เป็นหลัก** Figma เป็นแค่ reference

หน้าที่มี: Ingredient Scanner, Login, Home (EN + TH), รายการสูตร, โปรไฟล์, ตัวจับเวลาทำอาหาร, รายละเอียดสูตร

| จาก Cookmate | ใช้ไหม | ใช้ที่ไหน / เหตุผล |
|---|---|---|
| วันที่ + คำทักทายบนหัวหน้า | ใช้ (ตัดคำทักทาย/อีโมจิ) | หน้าหลัก: "วันศุกร์ 16 ต.ค." + "วันนี้" |
| ป้าย % เข้ากันบนการ์ดเมนู | ใช้ | แถวเมนูแนะนำ: "เข้ากัน 80%" / "ครบทุกอย่าง" |
| kcal + เวลาทำบนเมนู | ใช้ | แถวเมนู: "20 นาที · 300 kcal" |
| ชิปวัตถุดิบในตู้ (เลือก/ไม่เลือก) | ภายหลัง | อาจใช้ในแท็บสุ่มเมนูสำหรับล็อกวัตถุดิบ |
| สแกนเนอร์เต็มจอ + ชัตเตอร์กลาง | ใช้แนวคิด | แท็บสแกน (ตรงกับสเปกเดิมอยู่แล้ว) |
| ตัวจับเวลาทำอาหาร | ภายหลัง | หน้ารายละเอียดเมนู (ยังไม่อยู่ในสเปกหลัก — ถ้าจะทำ = เพิ่มฟีเจอร์ L3) |
| ภาพถ่ายอาหารขนาดใหญ่ | ไม่ใช้ | ทำให้หน้าดูเป็นโฆษณา และเราไม่มีภาพลิขสิทธิ์ของเราเอง |
| อีโมจิในหัวข้อ (มือโบก) | ไม่ใช้ | ผิดกฎเหล็กข้อ 1 |
| ช่องค้นหาบนหน้าหลัก | ไม่ใช้ | หน้าหลักเป็นรายงาน ไม่ใช่หน้าค้นหา |
| สีส้มอิฐเป็นสีหลัก | ไม่ใช้ | สีเน้นของเราคือเขียวสมุนไพรเดียว |
