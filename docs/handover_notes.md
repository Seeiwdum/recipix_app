## ค้างอยู่ / ปัญหา
- **ไม่มี persistence** — รายจ่าย/ของในตู้/การทำกินหายเมื่อปิดแอป ← แนะนำทำเป็นงานถัดไป (ADR-007: เก็บในเครื่องเท่านั้น)
- งบรอบ/วันเงินเข้า/ราคาต่อมื้อยังแก้ในแอปไม่ได้ (ตั้งใจให้อยู่ในแดชบอร์ด)
- ฐานสูตรมี 10 เมนู + ค่าประมาณการ → วุฒิตรวจ/เพิ่ม
- ยังไม่ทดสอบบนมือถือจริง (รอผู้ก่อตั้งติดตั้ง Android Studio — ขั้นตอนใน `engineering/tooling_setup.md`)
- ผู้ก่อตั้งจะวางไฟล์เดิม (Unity / เดโม HTML / ui_design_prompt) → เทียบกับ ADR-002 และชื่อเหรียญ

## ขั้นต่อไป (เสนอ)
1. Persistence ในเครื่อง (เลือก DB → ADR) สำหรับ ของในตู้, ตำแหน่งบนชั้น, รายจ่าย, การทำกิน, badge
2. แดชบอร์ด: แก้งบรอบ/วันเงินเข้า/ราคามื้อ (stepper), เส้นเวลาวัน, BudgetDeficit, Badge grid (คงแนวคิดเดิม)
3. สุ่มเมนู → สแกน (หลังมี Android)
4. รอผู้ก่อตั้งอนุมัติ: รายการซื้อของ, แจ้งเตือนเช้า, ปิดวันตอนค่ำ
