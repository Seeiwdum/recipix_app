# ADR-012: ทิศทาง UI v2 — "สมุดค่ากินในครัว" (Kitchen Ledger)

> brief ของ sprint อ้างชื่อไฟล์ `ADR-002_ui_direction_v2.md` แต่ ADR-002 ถูกใช้ไปแล้ว (BudgetDeficit) จึงใช้หมายเลข 012

- **ระดับ:** L2 (ผู้ก่อตั้งอนุญาตให้ทีมตัดสินใน sprint; เสนอทิศทางสำรองที่ CP2)
- **บริบท:** ผู้ก่อตั้ง: "minimal แต่ขาดอะไรไปหน่อย" ห้าม slop/โฆษณา; วินิจฉัยจาก 5 มุมมองอิสระ (`docs/design/critique/_synthesis.md`) ได้สมมติฐาน 5 ข้อ: ตัวเลขไม่มีภาษาเดียว, โครงเป็นการ์ดเทมเพลต, สีแดงไร้ความหมาย, สถานะว่างไม่จริง, วัตถุไม่มีมิติ
- **ตัวเลือก:** A สมุดค่ากิน / B ป้ายตลาด / C ภาษาชั้นวาง (`docs/design/direction_v2.md`) — คะแนน 27.5 / 24.5 / 20.5; C ไม่ผ่าน remove test

## การตัดสินใจ
เลือก **A** เพราะแก้สมมติฐานได้ครบ 5 ข้อ และแก้ด้วยการ **ลด** (กล่อง, สีแดง, ขนาดตัวอักษร) มากกว่าการเติม ซึ่งตรงคำเตือนของธนากร

กติกาที่ใช้ทั้งแอป:
1. **บรรทัดแทนกล่อง** — กล่อง/ขอบใช้กับวัตถุจริงเท่านั้น (ตู้เย็น, วงล้อ, ตะกร้า, sheet, ปุ่ม)
2. **หนึ่งจอ หนึ่งตัวเลขใหญ่** ไม่อยู่ในกล่อง
3. **Signature = dot leader** ระหว่างป้ายกับค่าในบรรทัด "อ่านค่า" เท่านั้น (component กลาง `LedgerRow`) — ห้ามใช้ตกแต่งหรือกับบรรทัดที่ไม่มีค่า
4. **ไวยากรณ์ตัวเลข** (component กลาง `Amount`): ตัวเลข tabular สีหมึก + หน่วยขนาด ~55% สีรอง เส้นฐานเดียวกัน
5. **สีความสดกลาง** (`freshnessColor`): หมดอายุ/วันนี้ = แดง, 1–5 วัน = เหลืองเข้ม, นอกนั้นไม่มีสี; เรื่องเงินไม่ใช้แดง ใช้หมึก + ประโยคทางออก
6. **ตัวอักษร 5 ขั้น** + micro: 44 / 24 / 18 / 16 / 13 (+10 สำหรับป้ายบนของ)
7. ตู้เย็น: ของในมือลอย (scale 1.05 + **เงาแข็งไม่เบลอ** ออฟเซ็ต 3px — ไม่ผิดกฎ "ห้ามเงาฟุ้ง"), วัสดุโซนด้วยเส้น, บอกเหตุผลเมื่อวางไม่ได้

## ทิศทางสำรอง (เสนอที่ CP2)
**B — ป้ายตลาด** แบบตัดรูปทรงตกแต่ง: วันหมดอายุ/ราคาเป็นป้ายมุม 10 ติดมุมภาพของ ใช้คู่กับกติกาข้อ 4–6 ข้างบนได้

## ผลที่ตามมา
- แตะเฉพาะ presentation + tokens + assets (ไอคอน); กติกาธุรกิจไม่เปลี่ยน ยกเว้นแก้ข้อบกพร่องการเลือกเมนู 0% ในตัวเลือกเมนูหน้าหลัก (provider ชั้น presentation)
- ทุกการเปลี่ยนจดใน `docs/design/changelog_ui.md` อ้าง R# และประเด็นใน synthesis
- เรื่องที่ไม่ทำในรอบนี้ (ต้องตัดสินแยก): ภาพจานอาหาร, แผนกินวนเมนูเดิม, เครื่องปรุงในแคลอรี่, เปลี่ยนตัวเลขหลักเป็น "มื้อ" (L3), เปลี่ยนชื่อแท็บแดชบอร์ด (L3)
