# ADR-017 — คำถามตอนเปิดแอปครั้งแรก + เว็บแอป

## บริบท
ผู้ก่อตั้งขอ (2026-10-17):
1. เว็บแอปสำหรับคนที่ไม่มี Android
2. เปิดแอปครั้งแรกให้ใส่ชื่อ และตอบคำถาม: ชอบกินอะไร, ปกติใช้ค่าอาหารเท่าไหร่, เหลือเงินเท่าไหร่

## การตัดสินใจ
### เว็บแอป (L3 ผู้ก่อตั้งเลือก "repo สาธารณะแยก")
- `.github/workflows/web.yml`: build web แล้ว push **เฉพาะไฟล์ที่ build แล้ว** ไป repo สาธารณะ `Seeiwdum/recipix_web` (branch `gh-pages`) ด้วย `peaceiris/actions-gh-pages@v4`
- ซอร์สโค้ดยังเป็น Private
- ต้องมี secret `WEB_DEPLOY_TOKEN`: fine-grained token ที่มีสิทธิ์ Contents: read/write เฉพาะ `recipix_web`
- ลิงก์: `https://seeiwdum.github.io/recipix_web/` (`--base-href /recipix_web/`)
- URL ใช้แบบ hash (`#/home`) ซึ่งเป็นค่าเริ่มต้นของ Flutter จึงรีเฟรชหน้าบน GitHub Pages ได้โดยไม่ขึ้น 404
- `manifest.json`/`index.html` ใช้ชื่อ Recipix และสีแบรนด์ บน iPhone กด Share → Add to Home Screen ได้
- บนเว็บ: โหมดบาร์โค้ดใช้ได้ ส่วนโหมดถ่ายของบอกว่าใช้ได้บนมือถือ (ADR-016) ข้อมูลเก็บใน localStorage ของเบราว์เซอร์นั้น

### คำถามตอนเปิดแอปครั้งแรก (L2)
- หน้า `/welcome` มี 3 ขั้น ขั้นละ 1 ปุ่มหลัก:
  1. ชื่อ (ต้องกรอก)
  2. เมนูที่ชอบ (เลือกได้หลายเมนู ข้ามได้)
  3. เงิน: เหลือเงินไว้กินเท่าไหร่ (ต้องกรอก), ปกติใช้ค่ากินเดือนละเท่าไหร่ (ข้ามได้), วันเงินเดือนออก
- **router gate**: ถ้ายังไม่ได้ตอบ ทุกหน้าจะพาไป `/welcome` ตอบเสร็จแล้วพาไป `/home`
- **ผลของคำตอบ** (`ProfileController.complete`):
  - **ติดตั้งใหม่** (ยังไม่มีข้อมูลของผู้ใช้ในเครื่อง): ตู้เย็นว่างและไม่มีรายการค่ากิน ข้อมูลตัวอย่างไว้สาธิตเท่านั้น ข้อนี้ตอบคำถามค้าง "เปิดครั้งแรกเริ่มจากตู้ว่างไหม" เพราะตอนนี้มีปุ่มเพิ่มของและสแกนแล้ว
  - **เครื่องที่มีข้อมูลอยู่แล้ว** (ผู้ทดสอบเดิม): ข้อมูลเดิมอยู่ครบ
  - งบรอบ = เงินที่เหลือที่ตอบ + ที่ใช้ไปแล้วในรอบ ทำให้ "เหลือ" ตรงกับคำตอบเสมอ
  - ราคาอาหารต่อมื้อ = ค่ากินต่อเดือน ÷ 90 มื้อ (3 มื้อ × 30 วัน) ปัดทีละ 5 บาท อยู่ระหว่าง 20–300 บาท
- **ใช้คำตอบ**:
  - หน้าหลักทักทาย "สวัสดี <ชื่อ>"
  - เมนูแนะนำเรียงเป็น: 1) เมนูที่ช่วยใช้ของใกล้หมด (ถ้าเป็นเมนูโปรดได้ก็เลือกเมนูโปรด) 2) เมนูโปรด (มีของก่อน) ป้าย "เมนูโปรด" 3) เมนูอื่นจากตู้ 4) เมนูทำง่าย
- **เก็บ**: `recipix.profile.v1` ในเครื่องเท่านั้น (ADR-007) ไม่มีบัญชี ไม่มี server

## ยังไม่ทำ
- แก้ชื่อหรือเมนูโปรดภายหลัง: งบ วันเงินเข้า และราคาต่อมื้อ แก้ได้อยู่แล้วในสมุดค่ากิน
- ถามอาหารที่แพ้หรือไม่กิน: ต้องมีข้อมูลสูตรรองรับก่อน
