# ADR-011: แท็บสุ่มเมนู

- **ระดับ:** L2 (สเปกแท็บอยู่ใน MASTER_PROMPT 5.3)

## ทำเอง (วงล้อวัตถุดิบ 3 แกน)
1. ผลสุ่มตัดสินใน core (`IngredientSlotMachine.spin`) **ก่อน** แอนิเมชันเริ่ม; วงล้อแค่เล่นผลที่รู้แล้ว (กติกา 3.1)
2. กลยุทธ์ตั้งต้น `ExpiringFirstRollStrategy` (ช่องติ๊ก "เน้นของใกล้หมดอายุ"), ปิดแล้วเป็น `PureRandomRollStrategy`
3. **แตะแกน = ล็อก** วัตถุดิบนั้นไว้รอบหน้า; ถ้าของที่ล็อกถูกใช้หมดไปแล้ว ล็อกหลุดเอง
4. **อันดับเมนูของสล็อตเปลี่ยน** (core `RecipeMatcher.rank(weighFocus: true)`): คะแนน = % เข้ากัน × สัดส่วนแกนที่เมนูใช้ — เดิมเมนูครบ 100% ที่ใช้แค่ 1 แกนชนะเมนู 80% ที่ใช้ครบ 3 แกน ซึ่งไม่ตรงกับความคาดหวังของคนหมุน; หน้าหลักยังใช้อันดับเดิม
5. แอนิเมชัน: แกน i หมุน 900 + 260·i ms (หยุดทีละแกน), ชะลอ easeOutCubic แล้วเลยเป้า 6% ของช่องแล้วกลับ (งบ overshoot ≤ 6%), แฮปติกเบาตอนแต่ละแกนหยุด; reduce-motion = ไม่เลื่อน เฟดอย่างเดียว
6. **ชื่อใต้แกนซ่อน ("กำลังหมุน") จนกว่าแกนนั้นจะหยุด** — ไม่เฉลยก่อน
7. หยุดครบ → bottom sheet: % เข้ากัน หรือป้าย "ครบทุกอย่าง" (ไม่มีพลุ), ของที่มี/ที่ขาด, เมนูอื่นที่ใช้ของชุดนี้ (แตะเพื่อดู); ปุ่มหลัก "ทำเมนูนี้" มีเฉพาะเมนูที่ครบ → ตัดของจากตู้จริง + เลิกทำ (เหมือนแผนกิน)

## สั่งข้างนอก
1. วงล้อเมนู 1 แกนจาก `assets/data/eat_out.json` (12 เมนู ราคาประมาณการ แก้ได้ภายหลัง)
2. สุ่มเฉพาะเมนูที่ราคา ≤ งบที่เหลือวันนี้ (งบวันนี้ − ที่จ่ายไปแล้ว); ไม่มีเมนูไหนพอ → เสนอเมนูที่ถูกที่สุดพร้อมบอกตรงๆ; ไม่ซ้ำเมนูเดิมติดกันเมื่อมีตัวเลือก
3. Sheet: ชื่อ ราคา "เหลืองบวันนี้ x บาทหลังมื้อนี้" หรือ "เกินงบวันนี้ x บาท"; ปุ่มหลัก "กินมื้อนี้ · บันทึก y บาท" → ลงบันทึกค่ากิน (นับเป็น 1 มื้อในแผน) + เลิกทำ

## ทดสอบ
`Random` ถูกฉีดผ่าน `randomSourceProvider` (test ใช้ seed คงที่) จึงสุ่มซ้ำได้และทำ golden ได้
