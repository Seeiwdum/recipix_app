# ADR-016 — โหมดถ่ายของ: กรอบรอบของด้วย ML Kit ในเครื่อง แล้วแตะเลือก

## บริบท
ผู้ก่อตั้งอยากให้กล้องตีกรอบรอบวัตถุและระบุว่าเป็นอะไร ตัวเลือกที่เสนอ (2026-10-17) มี 3 ทาง:
1. กรอบ + แตะเลือก (ML Kit ในเครื่อง)
2. ส่งภาพให้ AI บนคลาวด์
3. เทรนโมเดลเอง

ผู้ก่อตั้งเลือก **ข้อ 1** (L3) ซึ่งเปลี่ยนคำตอบ "ยังไม่ทำถ่ายรูปวัตถุดิบ" ใน ADR-014

ML Kit object detection (`google_mlkit_object_detection` 0.17.1, ในเครื่อง, ฟรี) ให้กรอบของแต่ละชิ้น จัดกลุ่มได้แค่กว้างๆ (ของกิน ของใช้ในบ้าน แฟชั่น ต้นไม้ สถานที่) **ไม่รู้ชนิดวัตถุดิบ** ผู้ใช้จึงต้องเลือกเองว่าเป็นอะไร

## การตัดสินใจ (L2)
1. แท็บสแกนมี 2 โหมด (`ModePicker` ตัวเดียวกับแท็บสุ่มเมนู): **บาร์โค้ด** (ADR-014) | **ถ่ายของ**
2. **ถ่ายภาพนิ่งแทนกรอบสด**
   - ใช้ `camera` 0.12.1 แสดงภาพกล้องและปุ่มชัตเตอร์วงกลม แล้วส่งภาพที่ถ่ายให้ ML Kit (`DetectionMode.single`, หลายชิ้น)
   - เหตุผลที่ไม่ทำกรอบสด: การแปลงภาพจากกล้อง (NV21/BGRA และการหมุน) ต่างกันในแต่ละเครื่อง และเราลองได้เฉพาะผ่าน APK บนเครื่องผู้ก่อตั้ง ความเสี่ยงที่ใช้ไม่ได้บนบางเครื่องจึงสูง
   - ภาพนิ่งยังให้แตะเลือกทีละชิ้นจากภาพเดียวได้
   - ถ้าผู้ก่อตั้งยังอยากได้กรอบสดหลังลองใช้ ค่อยทำเป็นงานต่อ
3. **ผลลัพธ์**
   - แสดงภาพพร้อมกรอบรอบของแต่ละชิ้น
   - แตะกรอบเพื่อเปิด `CatalogGrid` เลือกชนิด ของจะเข้าตะกร้า (ADR-013) และกรอบเปลี่ยนเป็นสีหลักพร้อมชื่อ
   - ถ่ายใหม่ได้ ถ้าไม่เจออะไรในภาพ จะบอกตรงๆ และมีทางไปเพิ่มของเอง
4. **ภาพอยู่ในเครื่องเท่านั้น**: ไม่ส่งออกนอกเครื่อง ไม่เก็บถาวร (ไฟล์ชั่วคราวของ `camera`)
5. การเพิ่มของจากภาพนับเป็น "สแกนของเข้าตู้ครั้งแรก" ด้วย (`BarcodeMemory.markScanned`)
6. **เว็บ**: ML Kit ไม่มีบนเว็บ โหมดถ่ายของจึงบอกว่าใช้ได้บนมือถือ (โหมดบาร์โค้ดยังใช้ได้)
7. กล้องเปิดทีละตัว: เปิดเฉพาะโหมดที่เลือก และเฉพาะตอนที่แท็บนี้แสดงอยู่

## ผลกระทบ
- dependency ใหม่: `camera`, `google_mlkit_object_detection` (+ `google_mlkit_commons`); แอป Android ใหญ่ขึ้นเพราะโมเดล ML Kit ถูกรวมมาในแอป
- ปิดเสียงตอนเปิดกล้อง (`enableAudio: false`) จึงไม่ต้องขอสิทธิ์ไมค์
- `ModePicker` ย้ายไป `lib/shared/widgets/`
