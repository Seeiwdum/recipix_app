# ADR-006: กติกาใบรายงานประจำวัน (แท็บหน้าหลัก)

- **ระดับ:** L2 (ปรับ requirement ย่อย)

## การตัดสินใจ
1. **นับของในตะกร้าด้วย** ในแคลอรี่/วันที่อยู่ได้ — ของซื้อมาแล้วอยู่ในบ้าน แค่ยังไม่ได้จัดเข้าตู้
2. **ตัวเลขหลักตัวเดียว:** "อยู่ได้อีก x.x วัน" ปัดลง 1 ตำแหน่ง (2.96 → 2.9) เพื่อไม่ให้ดูดีเกินจริง; ของปริศนาแสดงเป็นบรรทัด "อาจได้ถึง" แยก ไม่รวมในตัวเลขหลัก
3. **เส้นความคืบหน้า** = วันที่อยู่ได้ ÷ วันถึงเงินเข้า (สูงสุด 100%)
4. **เงินแสดงเป็นบาทเต็ม ปัดไปทางปลอดภัย:** ยอดขาดปัดขึ้น, งบต่อวันปัดลง (สูตรยังเป็นสตางค์ตาม ADR-002)
5. **"ต้องใช้ก่อน"** = ของหมดอายุแล้ว (ขึ้นก่อน) + ของเหลือ 0-2 วัน เรียงจากใกล้สุด; ปัดขวา = ใช้แล้ว, ปัดซ้าย = ทิ้ง, แตะ = sheet รายละเอียด; มี toast เลิกทำ
6. **เมนูแนะนำ 1 แถว:** อันดับจาก `RecipeMatcher` โดยต้องใช้ของเร่งด่วนอย่างน้อย 1 อย่าง (เรียง % เข้ากัน แล้วจำนวนของเร่งด่วนที่ใช้); ถ้าไม่มีของเร่งด่วน ใช้เมนูที่เข้ากันที่สุด; ไม่มีเลย = ไม่แสดง; 100% แสดงแค่ป้าย "ครบทุกอย่าง"
7. **งบตั้งต้น** 1,600 บาท, ไม่ตั้งวันเงินเข้า (= สิ้นเดือน) จนกว่าแดชบอร์ดจะให้แก้ค่าได้ (`budgetProvider`)
