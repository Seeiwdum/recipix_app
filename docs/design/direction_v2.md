# Design Direction v2

ทุกทิศทางต้องแก้สมมติฐาน 1–5 ใน `critique/_synthesis.md`; ส่วนที่เหมือนกันทุกทิศทาง (ไม่ขึ้นกับการเลือก):
- **สีมีความหมาย:** แดง = หมดอายุ/ต้องใช้วันนี้เท่านั้น; ใกล้หมด (1–5 วัน) = เหลืองเข้ม; เรื่องเงินใช้สีหมึก + ประโยคทางออก (ประเด็น 1)
- **สถานะว่างพูดจริงและบอกก้าวต่อไป** (ประเด็น 2)
- **ไวยากรณ์ตัวเลขเดียว:** ตัวเลข tabular สีหมึก + หน่วยเล็กลงครึ่งหนึ่งสีรอง ชิดเส้นฐานเดียวกัน ทุกที่ (ประเด็น 4; R3, R12)

---

## ทิศทาง A — "สมุดค่ากินในครัว" (Kitchen Ledger)
- **หลักการ**
  1. ข้อมูลเป็น **บรรทัด** ไม่ใช่กล่อง: ป้าย ซ้าย · ค่า ขวา · คั่นด้วยเส้นบาง (R5, R12, R15)
  2. หนึ่งจอ หนึ่งคำตอบ: ตัวเลขใหญ่มีที่เดียวต่อจอ ไม่อยู่ในกล่อง ที่เหลือเป็นบรรทัด (R6, R3)
  3. กล่อง/ขอบเก็บไว้ให้ **วัตถุจริง** เท่านั้น: ตู้เย็น, วงล้อ, ตะกร้า, sheet (R2, R8)
- **Signature:** **เส้นประนำสายตา (dot leader)** ระหว่างชื่อกับตัวเลข แบบใบเสร็จร้านข้าวตามสั่ง/สมุดบัญชี — ใช้เฉพาะบรรทัดที่ "อ่านค่า" (งบ, เงินเข้า, ยอดขาด, ราคา, ต้องใช้ก่อน) มีหน้าที่จริงคือพาสายตาจากชื่อไปหาตัวเลข
- **เปลี่ยนต่อแท็บ:** ตู้เย็น — ของในมือลอย (scale + เงาแข็งไม่เบลอ), โซนมีวัสดุด้วยเส้น (ขอบหน้าชั้น, เส้นคู่ช่องแช่แข็ง), บอกเหตุผลเมื่อวางไม่ได้, ของบนชั้นไม่มีกระเบื้องรอง / หน้าหลัก — เลิกกล่องรายงาน เหลือตัวเลขหลัก + บรรทัดบัญชี 3 บรรทัด ยอดขาด 2 แบบบอกที่มาชัด / สแกน — สถานะว่างที่บอกตามจริง / สุ่มเมนู — วงล้อเป็นหน้าต่างเดียวมีเส้นแบ่ง (เลิกกล่องซ้อนกล่อง), พักก่อนเฉลย, sheet ไม่บังวงล้อ, ผลสั่งข้างนอกเป็นบรรทัดบัญชีไม่ใช่โปรโมชัน / แดชบอร์ด — ตัวใหญ่ = ที่เหลือ, งบรอบเป็นบรรทัด + stepper, แท่งเกินงบเป็นเหลือง, เหรียญเป็นตราประทับไม่มีการ์ด บอก x/y
- **ความเสี่ยง:** ถ้าใส่ leader ทุกบรรทัดจะกลายเป็นลวดลาย → จำกัด "เฉพาะบรรทัดที่อ่านค่า"; โทนสมุดบัญชีอาจดูเป็นแอปการเงินมากไป → ถ่วงด้วยภาพวัตถุดิบและตู้เย็นที่คงไว้
- **Reference:** R3, R4, R5, R6, R12, R15 (+R8 ตู้เย็น)

## ทิศทาง B — "ป้ายตลาด" (Market Tag)
- **หลักการ**
  1. ข้อมูลที่เปลี่ยนบ่อย (วันหมดอายุ ราคา) เป็น **ป้ายเล็กติดกับของ** แบบป้ายเขียนมือในตลาด (R11, R13)
  2. วันที่แสดงรูปแบบเดียวทุกที่ (วัน + เหลือกี่วัน) (R1, R13)
  3. ภาพของคือพระเอก ข้อความรองลงมา (R2)
- **Signature:** **ป้ายแขวน (hang tag)** รูปทรงมีรูร้อยเชือก มุม 10 สำหรับวันหมดอายุ/ราคา ติดที่มุมภาพของ
- **เปลี่ยนต่อแท็บ:** ตู้เย็น — ป้ายวันเป็นป้ายแขวน / หน้าหลัก — แถวต้องใช้ก่อนมีป้ายแขวน / สุ่มเมนู — ราคาเป็นป้าย / แดชบอร์ด — แทบไม่เปลี่ยน
- **ความเสี่ยง:** ป้ายเป็นรูปทรงตกแต่งที่ต้องคุมไม่ให้โปรย (ธนากรเตือนเรื่องลายเซ็นทุกแท็บ); ไม่แก้ประเด็นกล่องซ้ำ/ตัวเลขขัดกัน/แดชบอร์ด ซึ่งเป็นหลักฐานแรงที่สุด; ฟอนต์ลายมือ (Ponlamai) ต้องซื้อ = L3
- **Reference:** R1, R2, R11, R13

## ทิศทาง C — "ภาษาชั้นวาง" (Shelf Language)
- **หลักการ**
  1. ทุกรายการ "วางอยู่บนชั้น": เส้นแนวนอนหนามีขอบหน้า แทนเส้นคั่นธรรมดา (R8, R9)
  2. ของทุกชิ้นมีน้ำหนักและ feedback ต่อชิ้น (R8)
  3. ความเรียบร้อย = รางวัล (R9)
- **Signature:** **ขอบหน้าชั้นวาง** (เส้นหนา 2px + เงาแข็งบาง) ใต้กลุ่มข้อมูลทุกกลุ่ม
- **เปลี่ยนต่อแท็บ:** ตู้เย็น — เหมือน A / หน้าหลัก — แถวต้องใช้ก่อนวางบนชั้น / แดชบอร์ด — เหรียญวางบนชั้น / สุ่มเมนู — วงล้อตั้งบนชั้น
- **ความเสี่ยง:** skeuomorphic เกิน (ธนากรเตือน texture/เงา); ชั้นวางนอกตู้เย็นไม่มีความหมายจริง = ตกแต่ง (ไม่ผ่าน remove test); แดชบอร์ดเงินไม่ใช่ชั้นวาง
- **Reference:** R8, R9, R2

## ธนากรตรวจตามหมวด 4

| ทิศทาง | อาการ slop/โฆษณาที่เสี่ยง | Swap | Remove | Ad | ผล |
|---|---|---|---|---|---|
| A | leader ทุกบรรทัด = ลวดลาย → **ผ่านแบบมีเงื่อนไข**: ใช้เฉพาะบรรทัดอ่านค่า; ตัวเลขใหญ่หนึ่งที่ต่อจอ | ผ่าน (บรรทัดบัญชี + ภาพวัตถุดิบ + ตู้ = แอปค่ากิน) | leader ลบแล้วเสีย "การพาสายตา" ในบรรทัดยาว → เก็บได้; กล่องรายงานลบได้ → ลบ | ผ่าน (บรรทัดบัญชีไม่ใช่ภาษาแบนเนอร์) | **ผ่าน** |
| B | ป้ายแขวนเป็นรูปทรงตกแต่ง, เสี่ยงลายมือปลอม | ผ่านบางส่วน | รูร้อยเชือกลบได้โดยไม่เสียข้อมูล → **ไม่ผ่าน remove test** ในส่วนรูปทรง | ป้ายราคาเหมือนป้ายโปรโมชันได้ | **ผ่านแบบมีเงื่อนไข** (ตัดรูปทรงตกแต่ง) |
| C | ชั้นวางนอกตู้เย็นไม่มีความหมาย, เงา/ขอบหน้าเสี่ยง skeuomorphic | ผ่าน | ขอบหน้าชั้นนอกตู้เย็นลบได้โดยไม่เสียอะไร → **ไม่ผ่าน** | ผ่าน | **ไม่ผ่าน — ตัดทิ้ง** |

## เลือก
**A — สมุดค่ากินในครัว** (ADR-012) · **สำรอง: B — ป้ายตลาด** (ตัดรูร้อยเชือกออก เหลือป้ายวัน/ราคาเป็นป้ายมุม 10 ติดภาพ) สำหรับเสนอผู้ก่อตั้งที่ CP2
