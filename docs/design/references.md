# References

## ตรวจความหลากหลาย
- 5 ทิศทางครบ: แอปสต็อก/ซื้อของ (R1, R2), งบประมาณ (R3, R4, R5), สูตร/บรรณาธิการ (R6, R7), เกม (R8, R9, R10), นอกแอป (R11–R15) + Figma ทีม (R16)
- รูปแบบไม่ซ้ำกัน: มีทั้งแอปมืด/สว่าง, เกม, งานพิมพ์, ป้ายเขียนมือ, ใบเสร็จ, สมุดบัญชี — ไม่ใช่ภาพ concept จาก Dribbble
- ร่วมกันหลายแหล่ง (สัญญาณแรง): **ข้อมูลเป็นบรรทัด + เส้นแบ่ง แทนกล่อง** (R5, R6, R12, R15) · **ตัวเลขได้รับการออกแบบเฉพาะ** (R3, R4, R12) · **วันที่/สถานะเป็น "ป้าย" ติดกับของ** (R1, R11, R13) · **feedback ต่อชิ้นของ** (R8, R9)
