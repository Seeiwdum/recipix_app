## 4. เปลี่ยนแล้วแต่ **ยังรอผู้ก่อตั้งยืนยัน (L3)**
- หัวข้อหน้าหลักเปลี่ยนจาก "อยู่ได้อีก x วัน" เป็น "ทำกินเองจากของในตู้ได้อีก x มื้อ" (ตัวเลขเดียวกับหน้าแผน) — สเปก 5.3 กำหนดเป็น "วัน"
- ชื่อแท็บ "แดชบอร์ด" → "สมุดค่ากิน"

ทั้งสองข้อมีเหตุผล (#4, R4/R5) แต่ชื่อแท็บและตัวเลขหลักอยู่ในสเปกของผู้ก่อตั้ง จึงเป็น L3 — ถ้าไม่อนุมัติ ย้อนได้ใน `strings.dart` + `home_page.dart` (ไม่แตะ logic)
