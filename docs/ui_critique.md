```

- [ ] Squint test / ขาวดำ
```

## Phase 1: app shell, tokens, ไอคอน, ภาพวัตถุดิบ (2026-10-16)
- [x] **ไม่มี Emoji**: ตรวจอัตโนมัติด้วย `test/governance_test.dart` (lib, assets, core)
- [x] **ไม่มี gradient/blur/glow/infinite animation**: governance test ห้าม `*Gradient`, `BackdropFilter`, `ImageFilter.blur`, `.repeat(`; สีอยู่ใน `lib/app/theme/` เท่านั้น; สีเน้นเดียวคือ accent `#2F6B4F`
- [x] **มุมมน 10/16/24**: governance test ห้ามตัวเลขรัศมีตรงๆ นอก tokens
  - ข้อยกเว้นที่ตั้งใจ: แถบบ่งชี้แท็บสูง 3px ใช้ปลายมน 3px (ปลายเส้น ไม่ใช่มุมการ์ด)
- [x] **Squint test**: หน้า placeholder มีหัวข้อหน้า + การ์ดข้อความเดียว; แท็บที่เลือกต่างจากแท็บอื่นทั้งด้วยสี น้ำหนักตัวอักษร และแถบด้านบน จึงยังอ่านออกเมื่อเป็นขาวดำ
- [x] **คอนทราสต์**: `test/tokens_test.dart` ตรวจทุกคู่ข้อความ ผ่าน >= 4.5:1
  - เจอระหว่างตรวจ: `warn #C98A1B` บนพื้นขาวได้ < 3:1 จึงใช้ทำข้อความไม่ได้ เลยเพิ่ม `warnText #8A5A0B` (โทนเดียวกัน เข้มกว่า) สำหรับข้อความ ส่วน `warn` ใช้กับขอบ/จุด/แถบเท่านั้น
- [x] **พื้นที่แตะ**: แต่ละแท็บกว้าง 1/5 ของจอ (>= 72px ที่ 360) สูง 64px
- [x] **ภาษาไทยไม่ตัดสระ**: golden 360/390/430 (`test/golden/goldens/`) วรรณยุกต์และสระบนไม่ถูกตัด ป้ายแท็บ 5 อันไม่ล้นที่ 360 (มีเทสต์ไม่เกิด overflow)
- [x] **เครื่องมือ ไม่ใช่โฆษณา**: ไม่มีแบนเนอร์ ภาพฮีโร่ หรือคำการตลาด; พื้นกระดาษ เส้นบาง ไอคอนเส้น
- [x] **รันจริงบน Chrome** (release, 390x800): สลับแท็บได้ครบ 5 แท็บ ภาพวัตถุดิบ 9 ชิ้น + ตัวอักษรย่อ "ก" + ของปริศนากรอบประ แสดงถูกต้อง
- [ ] **ต้องดูต่อบนมือถือจริง**: ครั้งแรกที่เปิดแท็บตู้เย็นบน web เฟรมทรานซิชันค้างระหว่างที่ SVG ถูก decode ครั้งแรก (ภาพที่จับได้ตอน 1 วินาทียังเห็นสองหน้าซ้อนกัน) ครั้งต่อมาปกติ → อาจต้อง precache SVG ตอนเปิดแอป (Phase 2)

ภาพหน้าจอ: `test/golden/goldens/home_{360,390,430}.png`, `fridge_{360,390,430}.png`

## แท็บตู้เย็น (minigame จัดตู้เย็น) — 2026-10-16
- [x] **ไม่มี Emoji**: governance test ผ่าน (รวมภาพวัตถุดิบ 18 ชิ้น)
- [x] **ไม่มี gradient/blur/glow/infinite animation**: เงา "ของในมือ" ใช้พื้น surface + เส้น 1px แทนเงาฟุ้ง; ไม่มีแอนิเมชันวนซ้ำ
- [x] **สีเน้นเดียว**: accent ใช้กับตัวกรองที่เลือก, กรอบช่องที่วางได้, แถบความจุ, ปุ่มหลัก; warn/urgent ใช้เฉพาะความสด
- [x] **มุมมน 10/16/24**: ตัวตู้ 24, ตะกร้า/ชิป/ปุ่ม/sheet 16-24, ช่องและของ 10
- [x] **ปุ่มหลักไม่เกิน 1**: หน้าตู้ไม่มีปุ่มหลัก; sheet มี "ใช้แล้ว" หรือ "จัดเข้าตู้ให้" อย่างเดียว ที่เหลือเป็นปุ่มข้อความ
- [x] **Squint / ขาวดำ**: ความสดอ่านได้ 3 ทางไม่พึ่งสีอย่างเดียว คือป้ายวัน ("วันนี้", "2 วัน", "หมดแล้ว"), กรอบสี, ภาพซีด
- [x] **คอนทราสต์**: ป้ายวันใช้ `warnText`/`urgent` บน surface (ผ่าน tokens_test)
- [x] **ไม่ล้นที่ 360/390/430**: เทสต์ไม่มี overflow + golden `fridge_{360,390,430}.png`
- [x] **เครื่องมือ ไม่ใช่โฆษณา**: หน้าตัดตู้เหมือนแผนผัง ตัวเลขความจุตรงๆ ไม่มีแบนเนอร์/พลุ
- [x] **รันจริงบน Chrome (release)**: ลากกะหล่ำจากตะกร้าไปชั้นล่างด้วยเมาส์ → snap เข้าช่อง ความจุ 14 → 16 ตะกร้าเลื่อนอุด

- [ ] **ต้องทดสอบบนมือถือจริง**: แฮปติกตอนวาง, ความลื่นของ spring ที่ 60 FPS, การลากด้วยนิ้ว (ยังไม่มี Android SDK)

## แท็บหน้าหลัก (ใบรายงานประจำวัน) — 2026-10-16
- [x] **ไม่มี Emoji / gradient / glow / infinite animation**: governance test ผ่าน; แอนิเมชันมีแค่นับเลข 400ms ครั้งเดียวและแถวเข้าจอเหลื่อม 30ms (สูงสุด 6)
- [x] **ตัวเลขหลักตัวเดียว**: "2.7 วัน" ขนาด display ที่เหลือเล็กกว่าชัดเจน
- [x] **ปุ่มหลัก**: หน้านี้ไม่มีปุ่มหลัก (การกระทำเป็นการปัดแถว) — ไม่เกิน 1
- [x] **ไม่มีการ์ดซ้อนการ์ด**: รายงานเป็นแผ่นเดียว; แถวรายการอยู่บนพื้นกระดาษ คั่นเส้น 1px
- [x] **สี**: เขียวใช้กับเส้นความคืบหน้าและ "งบพอ"/"ครบทุกอย่าง"; แดงใช้กับยอดขาดและของหมดอายุ/วันนี้; เหลืองเข้ม (`warnText`) กับ 1-2 วัน
- [x] **Squint / ขาวดำ**: ลำดับ = ตัวเลขใหญ่ → ยอดเงิน → รายการ ยังอ่านออก; สถานะในแถวเป็นคำ ("ควรใช้วันนี้") ไม่พึ่งสี
- [x] **ไม่ล้นที่ 360/390/430**: เทสต์ + golden `home_{360,390,430}.png`
- [x] **เครื่องมือ ไม่ใช่โฆษณา**: ไม่มีภาพอาหารใหญ่ ไม่มีคำทักทายตื่นเต้น (ต่างจาก Figma Cookmate โดยตั้งใจ)
- [x] **รันจริงบน Chrome**: ปัดขวาแถวข้าวสวย → หายไป ตัวเลข 2.7 → 2.5 วัน ยอดขาด 781 → 827 บาท toast "เลิกทำ" ขึ้น
- [ ] **ต้องดูบนมือถือจริง**: ความรู้สึกการปัด + แฮปติก
