# บันทึกตรวจ UI (เช็กลิสต์ MASTER_PROMPT 5.5)

รูปแบบต่อหน้าจอ:
```
## <หน้าจอ> — <วันที่>
- [ ] ไม่มี Emoji (grep ผ่าน)
- [ ] ไม่มี gradient/blur/glow/infinite animation; สีเน้นเดียว; มุมมน 10/16/24
- [ ] Squint test / ขาวดำ
- [ ] คอนทราสต์ >= 4.5:1, แตะ >= 44px, ไทยไม่ตัดสระที่ 360/390/430
- [ ] คนแปลกหน้าดูแล้วว่า "เครื่องมือ" ไม่ใช่ "โฆษณา"
ภาพหน้าจอ: <path>
```

## Phase 1: app shell, tokens, ไอคอน, ภาพวัตถุดิบ (2026-10-16)
- [x] **ไม่มี Emoji**: ตรวจอัตโนมัติด้วย `test/governance_test.dart` (lib, assets, core)
- [x] **ไม่มี gradient/blur/glow/infinite animation**: governance test ห้าม `*Gradient`, `BackdropFilter`, `ImageFilter.blur`, `.repeat(`; สีอยู่ใน `lib/app/theme/` เท่านั้น; สีเน้นเดียวคือ accent `#2F6B4F`
- [x] **มุมมน 10/16/24**: governance test ห้ามตัวเลขรัศมีตรงๆ นอก tokens
  - ข้อยกเว้นที่ตั้งใจ: แถบบ่งชี้แท็บสูง 3px ใช้ปลายมน 3px (ปลายเส้น ไม่ใช่มุมการ์ด)
- [x] **Squint test**: หน้า placeholder มีหัวข้อหน้า + การ์ดข้อความเดียว; แท็บที่เลือกต่างจากแท็บอื่นทั้งด้วยสี น้ำหนักตัวอักษร และแถบด้านบน จึงยังอ่านออกเมื่อเป็นขาวดำ
- [x] **คอนทราสต์**: `test/tokens_test.dart` ตรวจทุกคู่ข้อความ ผ่าน >= 4.5:1
  - เจอระหว่างตรวจ: `warn #C98A1B` บนพื้นขาวได้ < 3:1 จึงใช้ทำข้อความไม่ได้ เลยเพิ่ม `warnText #8A5A0B` (โทนเดียวกัน เข้มกว่า) สำหรับข้อความ ส่วน `warn` ใช้กับขอบ/จุด/แถบเท่านั้น
- [x] **พื้นที่แตะ**: แต่ละแท็บกว้าง 1/5 ของจอ (>= 72px ที่ 360) สูง 64px
- [x] **ภาษาไทยไม่ตัดสระ**: golden 360/390/430 (`test/golden/goldens/`) วรรณยุกต์และสระบนไม่ถูกตัด ป้ายแท็บ 5 อันไม่ล้นที่ 360 (มีเทสต์ไม่เกิด overflow)
- [x] **เครื่องมือ ไม่ใช่โฆษณา**: ไม่มีแบนเนอร์ ภาพฮีโร่ หรือคำการตลาด; พื้นกระดาษ เส้นบาง ไอคอนเส้น
- [x] **รันจริงบน Chrome** (release, 390x800): สลับแท็บได้ครบ 5 แท็บ ภาพวัตถุดิบ 9 ชิ้น + ตัวอักษรย่อ "ก" + ของปริศนากรอบประ แสดงถูกต้อง
- [ ] **ต้องดูต่อบนมือถือจริง**: ครั้งแรกที่เปิดแท็บตู้เย็นบน web เฟรมทรานซิชันค้างระหว่างที่ SVG ถูก decode ครั้งแรก (ภาพที่จับได้ตอน 1 วินาทียังเห็นสองหน้าซ้อนกัน) ครั้งต่อมาปกติ → อาจต้อง precache SVG ตอนเปิดแอป (Phase 2)

ภาพหน้าจอ: `test/golden/goldens/home_{360,390,430}.png`, `fridge_{360,390,430}.png`
